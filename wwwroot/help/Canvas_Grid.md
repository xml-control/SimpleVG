# Canvas, Grid & Snapping

SimpleVG provides precise grid tools and canvas configuration.

## View Controls

- **Grid Toggle**: Click the **Grid** button in the menu bar to show or hide the 10px grid pattern.
- **Snap Toggle**: Click the **Snap** button to turn magnetic grid snapping on or off.
- **Ruler Toggle**: Click the **Ruler** button to toggle the top/left measurement rulers and the canvas center reference lines (horizontal and vertical centerlines).

---

## Canvas Document Properties

Click on the **Canvas** tab in the right Inspector panel to configure:
- **Canvas Width & Height**: Change artboard dimensions (default `500 x 500`).
- **Grid Size (px)**: Adjust grid spacing (default `10px`).
- **Centerline Color**: Customize the color of the horizontal and vertical artboard centerlines using the SCADA color picker popover.
- **Default New Element Styles**: Set persistent default **Fill Color**, **Stroke Color**, and **Stroke Width (px)** for all newly drawn shapes.

---

> [!TIP]
> **Persistent User Settings**:
> SimpleVG automatically saves all your preference settings—including artboard dimensions, grid size, centerline color, default element styles, ISA-101 mode, rulers, grid, and snap states—to `localStorage`. Your custom setup will automatically persist across browser reloads and server restarts!
