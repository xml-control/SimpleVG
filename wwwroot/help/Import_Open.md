# Opening & Importing SVG Files

SimpleVG provides two distinct methods for loading external SVG vector files: **Open SVG** and **Import SVG**.

---

## 1. Open SVG vs. Import SVG

### A. Open SVG (`btn-open`)
- **Action**: Opens an external `.svg` project file and **replaces the entire canvas** artboard.
- **Use Case**: Use **Open SVG** when resuming work on a previously saved SimpleVG diagram project.

### B. Import SVG (`btn-import`)
- **Action**: Imports external `.svg` vector files directly into your **current active drawing canvas** without erasing your existing work!
- **Use Case**: Use **Import SVG** when merging external vector graphics, third-party icons, or additional SCADA symbols into your current operational diagram.

---

## 2. Smart Import Features & Auto-Scaling

When you click **Import SVG** and choose a file:

1. **Def & Gradient Preservation**:
   - SimpleVG automatically extracts and merges any `<defs>` (linear/radial gradients, custom line markers, pattern fills, and filters) from the imported file into the canvas definitions so color fills and shading remain intact.

2. **Proportional Auto-Scaling**:
   - The editor measures the bounding box of the imported artwork (`getBBox()`). If the imported SVG is oversized (larger than `350px`), SimpleVG automatically scales it down proportionally so it fits nicely on your artboard without overwhelming your view.

3. **Canvas Auto-Centering**:
   - The imported graphic is automatically translated and placed directly in the center of your active artboard.

4. **Group Selection**:
   - All imported SVG elements are grouped into a single selection node (`<g class="imported-svg-group">`) and selected immediately upon import with 8-point corner handles.

---

## 3. Notes & Usage Advice

> [!TIP]
> **Resizing & Transforming**:
> - To move an imported SVG, click and drag anywhere on its body.
> - To resize, drag any corner handle. SimpleVG uses group transform scaling (`scale(sx, sy)`), ensuring complex vector paths (curves, splines, arcs, sub-paths) scale smoothly without distortion.
> - To ungroup imported SVG elements into individual editable shapes, select the group and click **Ungroup** (`Ctrl+Shift+G`) in the top menu bar.

> [!IMPORTANT]
> **Grouped vs. Top-Level Elements (Moving & Scaling)**:
> - **Open SVG**: Loads SVG elements as independent, top-level shapes on the canvas stage. Clicking a single background shape moves only that shape. To move or scale an entire opened SVG composition together as a single unit, press **`Ctrl+A`** (Select All) and then **`Ctrl+G`** (Group).
> - **Import SVG**: Encapsulates all imported elements inside a single unified parent group (`<g class="imported-svg-group">`). This ensures background shapes, paths, sub-elements, and CSS keyframe animations stay locked together and transform seamlessly as a single unit!

> [!NOTE]
> **Clean SVG File Formats**:
> - SimpleVG imports standard SVG elements (`<rect>`, `<path>`, `<circle>`, `<polygon>`, `<g>`, `<text>`, `<polyline>`).
> - Bitmap image elements embedded inside SVG files (`<image>`) will also render cleanly inside the imported group.

> [!TIP]
> **Automatic AI & Gemini Namespace Sanitization & CamelCase Tag Preservation**:
> SimpleVG automatically detects and normalizes common namespace typos generated by AI models like Google Gemini (such as `xmlns="http://w3.org"` or missing `xmlns`). It also preserves official SVG specification **camelCase tag names** (`<linearGradient>`, `<radialGradient>`, `<clipPath>`, `<feGaussianBlur>`), ensuring gradients, filters, and clip masks render perfectly without parser errors!
