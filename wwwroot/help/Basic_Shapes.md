# Basic Vector Shapes

The **BASIC SHAPES** accordion section provides core primitives for custom vector drawing:

## Tools Overview

1. **Rectangle (`R`)**: Click and drag to create sharp or rounded-corner rectangles.
2. **Circle / Ellipse (`C`)**: Click and drag to draw circles or ellipses. Hold `Shift` to constrain to a perfect circle.
3. **Line (`L`)**: Click and drag to create a straight line connection.
4. **Polyline (`P`)**: Click multiple points sequentially to create connected multi-segment lines. Double-click to finish.
5. **Polygon**: Draw multi-sided polygons or triangles.
6. **Star**: Create multi-point star geometries.
7. **Arrow**: Draw line segments with directional arrowheads.
8. **Arc (`A`)**: Create smooth curved arc segments. Hold **`Shift`** while drawing to activate CAD **3-Point Arc Mode** (calculating circumcircle radius and curvature directly through your pointer). Hold **`Alt`** to invert standard sweep direction.
9. **Bézier Pen (`B`)**: Professional Pen tool for creating smooth cubic Bézier curves with control handles.
10. **Freehand**: Draw natural freehand pen paths.
11. **Text (`T`)**: Add customizable text labels with custom fonts, sizes, alignments, and colors.
