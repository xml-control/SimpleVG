# Keyboard Shortcuts

SimpleVG supports standard keyboard shortcuts to streamline your workflow:

## Tool Selection Hotkeys
| Key | Action |
| --- | --- |
| `V` or `Esc` | Select / Pointer Tool |
| `R` | Rectangle Tool |
| `C` | Circle / Ellipse Tool |
| `L` | Line Tool |
| `P` | Polyline / Path Tool |
| `A` | Arc / Curve Tool |
| `B` | Bézier Pen Tool |
| `T` | Text Label Tool |

---

## Clipboard & History Shortcuts
| Shortcut | Action |
| --- | --- |
| `Ctrl + Z` | Undo last action |
| `Ctrl + Y` or `Ctrl + Shift + Z` | Redo action |
| `Ctrl + C` | Copy selected shape(s) |
| `Ctrl + V` | Paste copied shape(s) |
| `Ctrl + G` | Group selected shapes |
| `Ctrl + Shift + G` | Ungroup selected group |
| `Ctrl + Shift + D` | **Radial Array / Circular Pattern (Petals)** |
| `Ctrl + Shift + F` | **Find Selected Element in XML Source Code** |
| `Delete` or `Backspace` | Delete selected shape(s) |

---

## Nudge Position & Rotation Shortcuts
> [!TIP]
> **Precision Nudging & Rotation**: Nudge selected shapes pixel-by-pixel or rotate shapes in 15° increments:

| Key | Action |
| --- | --- |
| `↑ Arrow` | Nudge Up 1px (`Shift + ↑` = 10px) |
| `↓ Arrow` | Nudge Down 1px (`Shift + ↓` = 10px) |
| `← Arrow` | Nudge Left 1px (`Shift + ←` = 10px) |
| `→ Arrow` | Nudge Right 1px (`Shift + →` = 10px) |
| `Ctrl + R` | **Rotate Clockwise (+15°)** |
| `Ctrl + U` | **Rotate Anti-Clockwise (-15°)** |
| `Ctrl + Shift + H` | **Flip Horizontal (↔)** |
| `Ctrl + Shift + V` | **Flip Vertical (↕)** |
| `Ctrl + J` | **Join / Combine Paths (🔗)** |
