# ISA-101 Gray HMI Mode

**ANSI/ISA-101.01** is the international standard for Human Machine Interfaces (HMI) in process automation. It recommends muted gray backgrounds and neutral symbol fills to minimize operator fatigue and highlight active alarms clearly.

## How to Enable ISA-101 Mode

- Locate the **ISA-101 Gray** checkbox located **above** the accordions at the very top of the left sidebar.
- Check the box to activate ISA-101 Mode.

> [!IMPORTANT]
> **Scope of ISA-101 Mode**:
> - When **ISA-101 Gray Mode** is enabled, all newly drawn vector shapes (rectangles, circles, lines, polygons, stars, arrows, arcs, beziers) AND newly dropped SCADA library presets (Pipes, Motors, Pumps, Valves, HVAC, Sensors, Facilities) are automatically created using neutral ISA-101 gray palettes (`#CBD5E0`, `#718096`, `#2D3748`) **as they are added to the canvas**.
> - To convert any existing symbol already on your canvas to ISA-101 gray, select the symbol and click the **⚙️ ISA-101 Gray** button inside the right Inspector panel.
