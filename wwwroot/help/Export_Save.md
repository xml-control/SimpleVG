# Saving & Exporting (SVG / PNG)

SimpleVG provides rich modal options for saving and exporting your operational vector diagrams.

> [!NOTE]
> Looking to load or merge external SVG files into your canvas? See [Opening & Importing SVG Files](Import_Open.md).

---

## 1. Save / Export SVG

Clicking **Save SVG** opens the SVG Export Options modal:

### Export Bounds Options
- **Full Canvas (500 × 500 px)**: Exports the complete artboard including canvas width, height, background grid/color, and all elements.
- **Tight Extents of Shapes (Auto-Crop)**: Automatically calculates the exact bounding box around all drawn shapes and crops the SVG viewbox tight to your artwork.
- **Selected Entities Only**: Exports **only the currently selected shape(s) or group(s)** on the canvas! Non-selected shapes are excluded, while preserving all gradient definitions and tag metadata.
- **Padding Margin (px)**: Specify custom padding margin in pixels (e.g. `10px`) around tight extents or selected entities boundaries.

> [!NOTE]
> Saved SVG files generated by SimpleVG preserve full SCADA tag metadata bindings, gradient defs, and clean SVG element structures for easy re-editing.

---

## 2. Export PNG Image

Clicking **Export PNG** opens the PNG Image Export Options modal:

### Background Fill Options
- **Transparent**: Transparent PNG background (ideal for overlays and web integration).
- **White (#FFFFFF)**: Solid white background fill.
- **Dark (#1A202C)**: Dark theme background fill.
- **Custom Color**: Pick any custom background color for the PNG export.

### Export Canvas Bounds
- **Full Canvas (500 × 500 px)**: Renders the full artboard dimensions.
- **Tight Extents of Shapes (Auto-Crop)**: Crops the PNG export tightly around all artwork with customizable padding margin (`0` to `100px`).
- **Selected Entities Only**: Renders a PNG image of **only the currently selected shape(s) or group(s)** with customizable padding margin (`0` to `100px`).

### Resolution Multiplier (Hi-DPI & Print Quality)
- **1x Standard**: Standard 100% resolution (default canvas size).
- **2x High-DPI (Retina Quality)**: 2x supersampled pixel resolution for crisp displays and presentations.
- **4x Ultra-HD (Print Quality)**: 4x ultra-high resolution rendering ideal for high-definition documentation, large operator displays, and print publications.

---

## 3. Live 2-Way SVG XML Code View & Find Selected

SimpleVG includes a bottom drawer featuring live 2-way SVG XML source code editing and instant element locating:

- **Expand / Collapse Code View**: Click **Live SVG XML Source Code** at the bottom footer bar (or click **Expand ▲**) to reveal the raw SVG XML text editor.
- **🔍 Find Selected in XML (`Ctrl + Shift + F`)**:
  - Select any shape, SCADA symbol, or path on the canvas and click **`🔍 Find Selected`** (or press **`Ctrl + Shift + F`**).
  - SimpleVG automatically expands the code drawer, searches the raw XML for your selected element's `id`, `data-tag`, `class`, or tag type, highlights the exact XML code segment, and smoothly **centers the highlighted line vertically** inside the code window!
- **Clean & Format XML (VB.NET)**: Clean and auto-indent the raw XML code using the server backend formatter.
- **Copy to Clipboard**: One-click copy of the live SVG XML source code.
- **Live 2-Way Editing**: Type or edit SVG code directly in the code editor to update the canvas in real time!
